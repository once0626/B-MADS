# 🛡️ B-MADS (Browser-based Malware Analysis & Detection System)

B-MADS is a browser-level malware analysis and detection system designed to enhance user security during file downloads. It scans files in real-time (or near real-time) and classifies them as **Safe**, **Suspicious**, or **Malicious** using signature-based and heuristic-based detection techniques.

---

## 🚀 Features

* 🔍 File scanning during download
* ⚡ Quick classification (Safe / Suspicious / Malicious)
* 🧠 Signature-based detection (known threats)
* ⚠️ Heuristic-based detection (unknown/suspicious patterns)
* 🌐 Browser-focused protection layer
* 📊 Simple and user-friendly interface

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python

---

## ⚙️ How It Works

1. User downloads a file
2. System intercepts and scans the file
3. File properties and patterns are analyzed
4. Detection logic is applied
5. Final verdict is displayed to the user

---

## ⚠️ Limitations

* No macro-based malware detection (e.g., VBA in documents)
* Limited deep behavioral analysis
* Not a full system-level antivirus

---

## 🔮 Future Scope

* 📌 Macro-based malware detection (VBA analysis)
* 🤖 AI/ML-based threat detection
* ☁️ Cloud-integrated real-time scanning
* 📡 Advanced behavioral analysis

---

## 🎯 Objective

To provide an additional layer of security at the browser level, which is one of the most common entry points for malware attacks.
